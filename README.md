# コメント先読み＆未視聴のみ

YouTubeを少し便利にする Edge / Chrome 用の拡張機能です。

- **コメント先読み**：サムネイルの💬ボタンを押すと、動画を開かずにその動画の人気コメントが読めます。
- **未視聴のみ**：チャンネルの「動画」タブで、見た動画（赤い再生バーが付いた動画）を隠して未視聴だけを表示します。ボタンに未視聴の本数も出ます。

APIキーや登録は要りません。開いているYouTubeのログイン状態をそのまま使います。

## ダウンロード

**[⬇ 最新版をダウンロード（YouTubeCommentSakiyomi.zip）](https://github.com/hakusyaku-lab/youtube-comment-sakiyomi/releases/latest/download/YouTubeCommentSakiyomi.zip)**

過去のバージョンは [リリース一覧](https://github.com/hakusyaku-lab/youtube-comment-sakiyomi/releases) にあります。

## 入れ方（Edge）

1. 上の「最新版をダウンロード」からZIPをダウンロードし、好きな場所に展開する
2. Edgeのアドレス欄に `edge://extensions` と入れて開く
3. 左側の「開発者モード」をオンにする
4. 「展開して読み込み」を押し、展開したフォルダ（`manifest.json` が入っているフォルダ）を選ぶ
5. YouTubeのタブを再読み込みする

Chromeの場合は `chrome://extensions` で、右上の「デベロッパーモード」をオンにしてから「パッケージ化されていない拡張機能を読み込む」を選びます。

## 使い方

### コメント先読み
- サムネイルにマウスを乗せると、左上に💬ボタンが出ます
- 押すと人気コメントが表示されます。「もっと見る」で続きも読めます
- 閉じるには × か Esc キー、またはパネルの外をクリックします

### 未視聴のみ
- チャンネルの「動画」「ライブ」「ポッドキャスト」タブで、「新しい順・人気の動画・古い順」の右にボタンが出ます
- 押すと見た動画が隠れ、もう一度押すと元に戻ります
- ▾ で「少しでも見た動画を隠す」と「最後まで見た動画だけ隠す（9割以上）」を選べます
- 本数は、YouTubeが読み込み済みの動画だけを数えます。下へスクロールすると増えていきます

## 注意

- 視聴済みかどうかは、今ログインしているアカウントの再生履歴で判断します。再生履歴がオフだと隠れません。
- YouTube側の画面や仕組みが変わると、動かなくなることがあります。
